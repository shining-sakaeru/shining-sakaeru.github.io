  8. Token Encrypt. 암호화.

    gem install travis

    travis login –pro

    travis encrypt GITHUB_TOKEN=<생성한 github token> -r <github username>/<repository>

    생성된 secure code를 .travis.yml 안에 위치한 secure 에 반영함
